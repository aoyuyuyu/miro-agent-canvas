# Miro 0.6

## 打开

双击便携文件夹里的「打开Miro.cmd」或「Miro.exe」。保留整个文件夹。
同一用户只运行一个 Miro；旧窗口存在时先关闭旧窗口。
本机使用当前 Codex 桌面聊天作为默认连接，保持 Codex 桌面打开。
源码目录双击「一键启动.cmd」也可运行；需要现有 Node 与已安装依赖。

## 操作

界面不显示软件名称、编号、文字按钮或设置。聊天正文与历史会话内容仍显示文字。
右边是实际软件头像；接入时提供个人头像则优先显示个人头像。未知软件没有提供头像时用中性人形图标。

| 操作 | 结果 |
|---|---|
| 点右下＋ | 直接复制接入提示词，成功后短暂显示勾号 |
| 点右侧头像 | 为该连接打开空白聊天视图 |
| 拖动会话顶端三点 | 移动会话框，连线跟随 |
| 点会话框红点 | 保存当前文字到历史栏并收起窗口 |
| 拖右边历史卡到画布 | 展开历史正文；历史原文件保持只读 |
| 点历史卡 | 直接展开历史正文 |
| 点历史栏红点 | 收起整栏，再点右侧时钟图标展开 |
| 共享输入的上方圆点连到会话底部左圆点 | 选择发送对象；可连多个 |
| 历史或会话的底部右圆点连到另一会话 | 整段文字放入共享输入，点箭头确认发送 |
| 输入后点箭头／按回车 | 发送，Shift+回车换行 |
| 滚轮／拖动画布空白 | 缩放／平移 |
| 选中连线按 Delete | 删除连线 |
| 点历史栏底部最右圆点 | 适应整个画布 |
| 点左上三个圆点 | 关闭／最小化／最大化应用 |

橙点表示当前连接有消息正在处理；绿点表示最近消息已有回复；灰色头像表示连接离线。
多个窗口仍对应同一个已连接 Agent 的当前原生聊天，不会自动在原软件新建或切换聊天。
历史正文默认显示最近 100 条，点顶部省略号继续显示更早消息。
文字发送上限两万字；超长接力可先缩减共享输入。失败仅显示提示图标，聊天内容会保留。
群发部分失败后，保持同一正文和连接目标再次发送，只重试失败对象。

## 接入与共享历史

点＋后将提示词贴给同一台电脑上具有终端执行权限的 Agent。
提示词引导注册、持续接收、回复与心跳，不需要新增依赖。
旧接入提示词不包含共享历史操作；需要向原 Agent 提供新提示词中的历史说明。
已有会话文件仍有效，新版接入工具可以使用它，不必重复注册。
邀请有效期一小时。超过七十五秒停止接收／心跳会显示离线；恢复接收重新在线。

按本轮明确授权，认证接入的 Agent 可以读取 Miro 内其他 Agent 的可见文字历史。
注册结果与每次接收结果包含共享目录、分页位置和支持的操作。
history-list 每页最多 200 项；history-read 每页最多 100 条；用 nextOffset 翻页。
history-publish 可导入 Agent 自己导出的其他会话，每批最多 200 条。
同一个 sessionId 稳定复用，offset 衔接前一批长度；重试相同 offset 不重复追加。
单个导入会话最多五万条或二十兆字节；仅保存 user/assistant 的可见正文。

| 软件 | 自动读取范围 |
|---|---|
| Codex | 本机原生文字目录与正文；默认连接是当前桌面聊天 |
| WorkBuddy／CodeBuddy | 本机 JSONL 可见文字 |
| Hermes | 本机数据库可见文字 |
| Claude | 兼容本机项目 JSONL；本机未发现此类记录 |
| Antigravity | 自动读取会话目录；特殊格式正文由 Agent 导出后发布，可与原目录合并 |
| 其他软件／自定义 Agent | Miro 收发记录；完整原生历史需 Agent 导出后发布 |

不能把注册成功当作全部原生历史已同步。图片、附件、工具输出、分支及隐藏思考过程尚未镜像。
不会把历史、令牌或会话文件上传其他服务。来源原文件不改写。
认证令牌仍按连接隔离；撤销的连接不能读取共享历史，网页跨站请求被拒绝。

## 数据

真实数据保存在当前用户的 AppData/Roaming/Miro。
canvas.json 保存画布，history/published.json 保存导入与收起的文字。
connections 保存接入凭据，不要放入源码或便携包。
便携版不需要安装，但仍使用同一用户数据位置；旧记录继续保留。
源码中 src/assets/avatars 是本机已安装产品的原图标，仅用于识别相应软件。

## 验证

自动检查覆盖原生历史、消息与凭据隔离、跨 Agent 分页读取、幂等发布、PowerShell 接入和撤销。
真实 Electron 窗口验证头像、加号直接复制、历史拖放、红点归档、两条曲线群发、移动与重载保存。
交互验证使用隔离的数据目录与模拟接收客户端，没有向真实 Agent 发送测试任务。
